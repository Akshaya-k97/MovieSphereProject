Why Cloud?

The reasons cloud infrastructure fits this project's scope.

Scalable Storage

Cloud storage allows datasets and processed results to be stored remotely without being tied to a single machine's disk capacity.

Remote Accessibility

The application can be accessed from different devices through deployment, rather than only being reachable on the developer's local machine.

Data Availability

Processed data and application resources can be made available through cloud infrastructure, reducing the risk of data loss on a single system.

In this project, PySpark processing runs on the developer environment while S3 stores datasets and outputs. Cloud processing (e.g. EMR) is out of scope — the cloud component here is storage and deployment.
